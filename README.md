# Soytec organization profile

This repository contains Soytec's public [organization profile](profile/README.md), [project roles](GOVERNANCE.md) and the proposed [architecture and service extraction](ARCHITECTURE.md).

The profile uses the existing Soybert mascot, copied without modification from [`apps/web/public/brand/soy-mascot.png`](https://github.com/soytec/napplet-soy/blob/b5acb199a8f49a443a153a9d036ee642f7f8460d/apps/web/public/brand/soy-mascot.png). The original repository's MIT license is preserved in [LICENSE](LICENSE).

The existing repository has transferred to [soytec/napplet-soy](https://github.com/soytec/napplet-soy), preserving its history, issues, pull requests and releases. Standalone CLI source now lives in [soytec/soyli](https://github.com/soytec/soyli); the shell and hosted services still need to switch to its supported artifacts. The [napplet-services](https://github.com/soytec/napplet-services) repository is a bootstrap for the proposed backend extraction. No hosted runtime has moved there yet.
