# Soytec organization profile

This repository contains Soytec's public [organization profile](profile/README.md) and [project roles](GOVERNANCE.md).

The profile uses the existing Soybert mascot, copied without modification from [`apps/web/public/brand/soy-mascot.png`](https://github.com/soytec/napplet-soy/blob/b5acb199a8f49a443a153a9d036ee642f7f8460d/apps/web/public/brand/soy-mascot.png). The original repository's MIT license is preserved in [LICENSE](LICENSE).

The existing repository has transferred to [soytec/napplet-soy](https://github.com/soytec/napplet-soy), preserving its history, issues, pull requests and releases. The shell, Studio and soyLI remain together there until the separate soyLI extraction.
